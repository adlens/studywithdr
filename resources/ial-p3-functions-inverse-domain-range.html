Key ideas at a glance

Functions and function notation

A function assigns exactly one output to each input in its domain. f(x) is the output when the function f is applied to the input x.

Composite functions

The composite function fg(x) means f(g(x)): apply g first, then apply f to the result. The order matters, and in general fg(x) is not the same as gf(x).

Inverse functions

The inverse function f⁻¹ reverses the effect of f. It exists only when f is one-to-one. The domain of f⁻¹ is the range of f, the range of f⁻¹ is the domain of f, and the graph of y = f⁻¹(x) is the reflection of y = f(x) in the line y = x.

Domain and range

The domain is the set of inputs a function is defined for. The range is the set of outputs it produces from that domain.
